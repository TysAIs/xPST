xPST

Cross-post short-form video to YouTube, X, Instagram and TikTok from one command. xPST is an open-source, MIT/Apache-2.0 licensed CLI and desktop app for automated video distribution. Manage captions, captions library, analytics, scheduling and cross-posting from a single tool.

Getting started

pip install xpst
xpst wizard
xpst connect youtube
xpst post -v PATH
