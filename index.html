xPST — Cross-Posting Suite

Post once, publish everywhere. Local-first, open-source cross-posting for short-form video: one run publishes to YouTube Shorts, X, Instagram Reels and TikTok at full native quality.

xPST is dual-licensed MIT OR Apache-2.0. It runs three ways from the same engine: a native desktop app, a command-line interface with JSON output for automation, and an MCP server so AI agents can drive it. All data lives on your machine under ~/.xpst/ — credentials encrypted at rest, no telemetry, no hosted account.

Features

  • Multi-source: watch TikTok, Instagram, YouTube, X or a local folder for new videos and cross-post them automatically.
  • Multi-destination: publish to YouTube Shorts, Instagram Reels, X and TikTok in one run, with per-platform caption templates, hashtags and scheduling.
  • Quality pipeline: FFmpeg transcode with per-platform bitrate/aspect tuning; upload retries with circuit breakers and rate-limit-aware quotas per platform.
  • Analytics: per-post views, likes, comments, shares and follower snapshots in one dashboard, across every connected platform.
  • Captions library & ideas: reusable caption sets, transcript lookup and a personal knowledge base of your published content that connected AI agents can query.
  • Agent-friendly CLI: deterministic JSON on non-TTY shells, structured exit codes, --dry-run everywhere; 28 MCP tools for full automation.

Getting started

pip install xpst
xpst wizard            # interactive setup: sources, destinations, captions
xpst connect youtube   # OAuth in your browser (one click)
xpst connect x         # guided sign-in
xpst health            # verify all connections
xpst run               # check sources and cross-post what's new
xpst run --dry-run     # preview decisions without posting

The desktop app (xpst app) shows the same flow with an onboarding wizard, a Connect page with per-platform setup guides, a compose page, scheduling and analytics.

How a run works

  1. Check sources — new videos since the last checkpoint are fetched with yt-dlp (HD, cookies optional).
  2. Deduplicate — state store tracks every cross-post group so nothing posts twice.
  3. Prepare — captions, hashtags and per-platform formatting applied from templates.
  4. Publish — uploads go out per platform with quota-aware pacing; failures retry and a circuit breaker pauses a degraded platform without blocking the others.
  5. Collect metrics — views/likes/comments/shares snapshotted per post into the analytics store.

FAQ

Does it need a subscription or account?

No. xPST runs entirely on your machine. There is no vendor account, cloud queue or telemetry.

Where are credentials stored?

Encrypted files under ~/.xpst/credentials/ (or the OS keychain if preferred). Nothing is sent anywhere except the platform APIs you configure.

Can an AI agent operate it?

Yes — every CLI command is agent-safe (auto-JSON when not attached to a terminal, meaningful exit codes), and the built-in MCP server exposes 28 tools covering posting, scheduling, analytics and configuration.
